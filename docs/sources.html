Organizer GitHub repository · README inspected via GitHub API

GEMS Prize reference solution

The repository README states that users download competition data from the competition website and place it in data/. It documents CPU-only as well as GPU environments and says training is faster on a GPU. The reference notebook uses a patch-based U-Net workflow, Tversky loss, and sigmoid predictions; its example writer copies CRS/transform from the label raster and does not independently re-read the file for range or sample-grid validation. These observations describe the reference code only—not the competition's exact scoring implementation, an H33 artifact, or a current score. This repository contains the reference solution, not this project's missing competition data or the requested shared evaluator/writer.
