Decision and next validation step

The first research lead is ASTER TIR alteration mapping because it adds a different physical measurement—spectral mineralogy—rather than another variant of the existing prediction surface. That is a rationale for studying it, not a claim that its input exists or that it will improve DTI. The official product page and study-area granules must first be obtainable and documented. Until then, this is a blocked research lead, not a viable candidate.

Before a holdout run, restore the shared template and document its exact cached-stack path, evaluator version, and writer. Confirm a single selected lane; the initiating text does not contain the method paragraph it references. Then freeze the feature set, derive every catalogue-dependent layer from visible faults only, run the single-feature leakage canary, and evaluate the candidate against the current holdout best. No weekly submission slot should be considered unless the holdout gate is passed.

Uniqueness is not established. The branch contains no registry rasters, and the provided historical site list is not a pixel-level registry. A method's name sounding different is insufficient: the surface correlation and dot-overlap checks must be run before placement and on the final dots.

Learning from the H33 archive without copying it

The H33-2-B2 entry in the related GEMSDOE32 archive is described as suppressing predictions close to the known-fault catalogue on top of an existing emission. That is a different operation from adding an independent sensor-derived physical feature. The archive's own site/readme labels its displayed live value a projection and says it has no organizer score for its artifacts. We use that record only to understand the approach and its evidence limitations; no raster or private fork was copied.

A catalogue-distance ablation is scientifically interpretable only if the holdout hides whole fault segments with a buffer, computes all catalogue-derived features from the visible catalogue, and masks visible-fault pixels exactly. Otherwise it can reward leakage or the spatial structure of the target rather than discovery of new faults.

Pruning a near-catalogue belt is a precision/recall policy, not a geological observation: it can remove false-positive mass, but it can also delete true withheld faults. Its effect depends on the exact pooled DTI implementation and spatial kernel. The prescribed HOLDOUT-DTI parameters are alpha 0.2, beta 0.8, and a 300 m triangular kernel; these protocol settings are not a result. Convention differences in Tversky implementations make it unsafe to infer which error term dominates without checking the competition evaluator.

What the organizer reference solution does—and does not show

The organizer's public reference notebook trains a U-Net on raster patches over repeated random splits, uses a Tversky loss with greater penalty weight on false negatives than false positives, and converts logits to probabilities with sigmoid. Its example output writer copies georeferencing from the fault-label raster. This is a baseline implementation, not evidence that the H33 candidate was scored or that its method caused a score change.

Random patch splits can leave nearby or spatially correlated examples on both sides of a split; that risk is why GEMSDOE74's required decision gate is a spatial holdout that hides complete fault segments. The example notebook also does not re-read and validate the written output's range and does not compare its grid with the official sample-submission raster. A mathematically bounded sigmoid output is not a substitute for post-write file validation.
