Ranked shortlist — qualitative only

All items use the H74-A observation family: the GDR spring/well catalogue and GeoDawn K/Th radiometric bands. No new data layer is proposed here. For each holdout fold, any catalogue-derived filtering must be recomputed from that fold's visible-fault mask; the historical full-catalogue dist_known_fault_px field is not acceptable for a hide-and-recover test.

1 · test first Fold-visible spring-chain geometry. Use the existing GDR spring/well coordinates and documented thermal classes/temperatures. Recompute each spring's distance to visible faults only for every fold; derive the pre-registered chain/orientation feature from springs beyond that visible-fault threshold. Aligned hydrothermal discharge can trace permeability along a blind structure that has little surface relief. The signal is independently observed at springs, but its use as an off-catalogue prior must be evaluated on whole withheld segments. Relative potential: highest, very uncertain. Cost: high—fold-aware rebuild, provenance/field checks, fixed parameter preregistration, and repeated spatial holdout. Test this first against the current valid holdout best. Well/spring survey density, road access, sampling bias, non-fault geothermal discharge, and regional hydrology can make false chains. Source coverage and field semantics are unverified in this workspace. Do not reuse the historical full-catalogue distance column in any fold.
2 Spring–alteration consensus rather than a union. Require a spring-chain orientation signal to coincide, within a preregistered distance, with a spatially coherent K-rich / low-Th-to-K alteration response. Keep the spring and radiometric terms separately measurable. Agreement between discharge alignment and an independent radiometric alteration signature could suppress isolated springs or isolated radiometric edges that do not indicate a shared fluid pathway. Relative potential: medium-high if rank 1 is useful. Cost: medium—one fixed coincidence/scale rule plus paired ablation on identical folds. Lithologic contacts, radiometric striping/quantization, altered host rock without a fault, and chance coincidence can mimic agreement. Proceed only after the spring-only test and feature-alone leakage canaries.
3 K/Th alteration lineaments alone. Use only GeoDawn bands whose metadata confirms the K and Th identities/units. Build a scale-controlled lineament response from the documented alteration contrast; do not infer calibrated geochemistry from an undocumented stretched byte raster. Hydrothermal alteration can mark fluid pathways where a geomorphic fault trace is weak. This ablation tests whether the radiometric contribution adds signal independently of spring locations. Relative potential: medium-low. Cost: medium—source metadata, masking, background normalization, and lineament parameter checks. Lithology, surficial cover, flight-line artifacts, and resampling edges may dominate. No improvement is assumed; verify K and Th provenance, then run one-feature AUC canaries and the spatial holdout.
4 Thermal-class/temperature weighting within spring chains. Compare a pre-registered hot-only or quality-weighted spring subset with the hot-plus-warm set; do not tune thresholds against the holdout. More reliable, higher-temperature observations might strengthen a genuine hydrothermal conduit signal and reduce low-confidence or non-geothermal spring records. Relative potential: low-to-medium. Cost: low after rank 1's builder exists; medium if source-field definitions need reconciliation. Season, instrument, measurement date, and survey practice can control reported temperatures. Only test if GDR field semantics and dates are verified, and compare at matched emitted mass.

Decision and next validation step

Rank 1 is the first research test, not a submission choice. The stored H74-A raster is not its result: the archived generator filters springs with a full-catalogue distance field, so it cannot currently produce a valid fold-specific hide-and-recover candidate. The shared evaluator has been repaired to require whole-segment folds, a 1.5 km feature-construction collar, exact pixel masking of visible faults, pooled DTI with the 300 m kernel, repeated draws, and a 95% interval. The local checkout still lacks data and a fold-aware builder; no evaluation was run.

  1. Obtain the official competition inputs and verify their hashes, grid, licence, and source. The pinned GitHub mirror is partial and was not fetched.
  2. Refactor the shared H74-A generator so its spring-distance field is recomputed from the fold's visible faults; do not retain or read the historical full-catalogue distance column for evaluation.
  3. Freeze the candidate parameters and evaluate rank 1 against a valid current holdout best using identical segment draws. If no valid baseline exists, remain blocked.
  4. Run each feature-alone leakage canary. AUC above 0.90 is leakage until explained; record every feature and fold.
  5. Compare the surface before placement and the final dots with every registry raster. Stop if rank correlation exceeds 0.90 or more than 70% of dots fall within 3 px of a registry raster.
  6. Only after a candidate beats the holdout best may the separate selector consider a weekly slot. This page does not select or promote a submission.
Budget: no experiment was run in this session. Stop after at most three experiments or two hours. The archived raster is not a baseline, and its format receipt is not an organizer score.
