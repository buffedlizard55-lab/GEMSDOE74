When a future candidate is cleared

  1. Use only authorized data with recorded source, date, hash, and rights. The official competition data page currently redirects to login in this environment.
  2. Check the model has beaten the incumbent under the required spatially blocked, whole-segment-with-buffer holdout, with leakage canaries and 95% CI; format-only checks are insufficient.
  3. Write a single-band float32 GeoTIFF whose CRS, 100 m resolution, bounds, shape, transform, and outside-bounds mask match the official sample. The official problem page says outside-bounds data should be null or NaN, and values are in [0,1].
  4. Re-open the written file and verify range, finiteness inside the footprint, CRS, shape, transform, one-band count, and SHA-256. Keep a machine-readable validation receipt.
  5. In DrivenData's competition submission form, choose the GeoTIFF or a ZIP containing one GeoTIFF. Enter an optional short experiment note (≤140 characters in this project's convention; check the live form's actual limit).
  6. Save the submission-page receipt. Only that receipt can support an ORGANIZER-CONFIRMED result.
