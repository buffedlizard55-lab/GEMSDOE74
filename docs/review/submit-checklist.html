Before any future submission

  2. Use the actual sample submission to check CRS, shape, transform, and valid footprint.
  3. Run the required whole-segment-with-buffer hide-and-recover, visible-only feature construction, pixel-exact masking, pooled DTI, confidence interval, random/control and incumbent comparisons.
  4. Run feature-alone leakage canaries, registry rank-correlation and dot-overlap checks. Stop and log a duplicate above the defined threshold.
  5. Write a unique TIFF, reopen it, validate values and template geometry, record a ≤140-character note, then use the independent selector for any weekly slot.
  6. Save the organizer's submission receipt before reporting any score as ORGANIZER-CONFIRMED.
