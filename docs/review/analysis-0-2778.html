Why sparse, well-targeted predictions can be plausible

The official problem description defines distance-weighted Tversky scoring with a triangular distance kernel and asymmetric penalties. If a prediction lies close to a truth fault, it can receive partial credit; far-away prediction mass contributes little credit while still adding false-positive cost. Therefore, for a fixed output budget, reducing redundant or poorly placed dots can plausibly improve the score. This is an explanation of the metric's incentive, not proof of why a named raster scored a certain value.

The task prompt and prior GEMSDOE32 site descriptions mention sparse Poisson spacing and excluding known faults. Those are owner-provided methodological claims here, not independently reproduced findings. Establishing their causal contribution would require the original raster, the exact organizer evaluator, controlled ablations, and an organizer receipt.
