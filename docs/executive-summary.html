After independent promotion

  1. Recover the genuine shared cache, source rights and real template. Validate feature names and grid metadata.
  2. Run buffered whole-segment hide-and-recover, recomputing catalogue features from visible faults only. Require pooled DTI, withheld-positive count, block-bootstrap confidence interval and valid feature canaries.
  3. Compare against the incumbent on identical folds. Check the entire registry before placement and final dot overlap after placement. Unknown comparisons block release.
  4. Write a unique single-band GeoTIFF using the existing writer. Reopen bytes; validate shape, CRS, transform, finite footprint values and range [0,1]. Use a unique name and note no longer than 140 characters.
  5. A separate selector checks the current weekly cap and rules. Only then use the competition's New submission form, select the promoted TIFF and paste its note.
  6. Save the organizer's submission-page receipt and file hash. Only a score from that receipt may be labeled ORGANIZER-CONFIRMED.

Range error troubleshooting

Reject NaN or infinity inside the footprint and reject negative nodata sentinels or values above one. Do not clip unknown bad inputs into apparent validity. All-finite zero-outside output avoids numeric NaN/sentinel ambiguity but does not guarantee portal acceptance; the authenticated organizer template and current rules still govern.
