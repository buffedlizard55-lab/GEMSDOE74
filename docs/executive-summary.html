What local format inspection did—and did not—establish

The zero-filled fixture reopened locally as a single-band float32 GeoTIFF with dimensions 3730×3292, EPSG:32611, transform (100, 0, 243350, 0, −100, 4508550), no nodata tag, finite values in [0,1], and 35,641 positive cells. The same basic properties were observed for the H74-A zero-filled fixture, with 39,500 positive cells. These are MEASURED-LOCAL format facts, not competition scores and not evidence of spatial correctness.

  • Actual `sample_submission.tif` is absent, so exact CRS/shape/geotransform/footprint matching to the competition template is not independently verified.
  • The local validator's catalogue check was skipped because the labels are absent.
  • The files were generated using synthetic surfaces/targets or unverified provenance. The legacy generator hard-coded some evaluation and registry fields.
  • All zero-filled cells—including outside any footprint—are finite and in range, which avoids a negative sentinel/NaN range failure but does not establish the competition portal's exact treatment of outside-footprint predictions.

Why the previous range error can recur

The portal message “Predicted values must be in range [0, 1]” is consistent with predictions containing a negative nodata sentinel or non-finite values treated as predictions. A local writer should use a valid prediction array, avoid writing sentinels into data cells, and reopen the written TIFF to check finite values and [0,1]. This does not establish what the organizer validator accepted; only an actual portal receipt can do that.

The old repository pages asserted two specific causes and claimed competition-specific measurements. The relevant official files are not present in this checkout, so those causal measurements are not independently reproducible here. See the audit and irregularity log.

How to submit once a future candidate is genuinely cleared

  1. Download the uniquely named `.tif` from the candidate's release panel only when it explicitly says OK TO SUBMIT and links to an audit receipt.
  2. On the DrivenData DOE GEMS competition, open Submit → New submission.
  3. Choose the single-band `.tif` (or a ZIP containing exactly one GeoTIFF), enter its unique name and ≤140-character note, and submit.
  4. Keep the submission-page receipt. Record its score only as ORGANIZER-CONFIRMED and do not infer a score from local holdout results.

Before any release, verify the actual official template match, validate file values after writing, run the compliant spatial holdout and leakage canary, perform registry duplicate checks, document input provenance/rights, and pass the independent slot selector.
