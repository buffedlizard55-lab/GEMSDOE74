Repository and lane

RESOLVED · confirmed by merged project brief

The active lane is H74-A

The initiating text's reference to a “single method paragraph” was ambiguous on the starting revision. Current upstream main now names H74-A—hydrothermal spring chains plus potassic K/Th alteration halos—as the chosen lane. The site and research backlog use that lane only; alternate method families are not being proposed as replacements.

BLOCKER · current local state

The starting revision had only a README; main adds code but not the required data/cache

This branch began from a single README. The merge adds shared scripts and evidence, but no local competition rasters, complete official training feature stack, cached feature stack, complete registry, or verified organizer data receipt is present. The pinned mirror is partial and was not run.

BLOCKER · confirmed by code review

The legacy H74-A generator uses a full-catalogue spring-distance field

scripts/generate_submission.py reads the historical dist_known_fault_px field from its spring table. That is catalogue-derived; it is not recomputed from each fold's visible faults. The builder is marked unapproved and guarded from running by default. It must be made fold-aware before its output can be used in a hide-and-recover evaluation.

BLOCKER · no complete registry

Uniqueness has not been established

No complete registry of past rasters is available in this checkout. The archived H74-A raster alone is insufficient for the required surface-correlation and final-dot overlap checks. A method name or a local build hash is not proof of uniqueness.

REPAIRED IN CODE · not run on competition data

The shared holdout evaluator now fails closed

scripts/evaluate_holdout.py delegates to the repaired shared segment engine. It implements whole 8-connected fault-segment draws, a 1.5 km feature-construction buffer, exact pixel masking of visible faults, pooled DTI, repeated-draw 95% intervals, and fold-aware callbacks for catalogue-dependent features. The CLI only accepts an explicitly declared catalogue-independent fixed surface. The real-data evaluator remains unrun because inputs, cache, fold-aware H74-A builder, and valid baseline are missing.
