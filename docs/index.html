The path from hypothesis to a real submission

  1. Restore the full official inputs and shared feature cache; document source hashes.
  2. Repair and use the shared evaluator and writer; preregister a single method lane.
  3. Run feature-alone leakage checks, then the buffered whole-segment spatial holdout against the current holdout best.
  4. Check the candidate surface and final dots against the registry before any live slot.
  5. Generate through the shared writer; independently validate the GeoTIFF, preserve receipts and SHA-256, and only then expose a download with a unique name and note.
