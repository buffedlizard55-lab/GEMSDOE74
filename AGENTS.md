# Agent session instructions

Before each session, read `README.md` in full. It is the canonical project brief and contains the experiment protocol, current evidence boundary, limitations, and checklist.

Do not create a submission TIFF unless the required data, shared feature stack, shared holdout evaluator, shared writer, registry rasters, passing holdout/leakage/uniqueness checks, and independent validator receipt are all present. Never copy an earlier submission or invent a score. Keep the site status blocked until the readiness audit confirms all gates; do not describe the present missing-file state as submit-ready.
