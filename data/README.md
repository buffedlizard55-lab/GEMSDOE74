# data/ (placeholder)

Put the official DrivenData competition files here. This folder is git-ignored, and so are its contents, except this README.

The competition data requires login at https://www.drivendata.org/competitions/306/competition-doe-gems/ and cannot be downloaded automatically.

Files the pipeline is expected to need (confirm names against the official download):

- training features (GeoDAWN measurements and other public features)
- labels (from the INGENIOUS compilation, see GDR 1391)
- the sample submission, for format reference
- optionally, USGS 1 m DEM tiles (rules §3.3)

Do not place third-party mirror copies here without confirming their rights (see docs/irregularities.html, IR-74-04).
